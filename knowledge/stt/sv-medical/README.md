# sv-medical — Swedish clinical speech-to-text profile

Vocabulary, benchmark and loop configuration for transcribing patient speech in Swedish. Full documentation: [docs/en/knowledge/02-clinical-stt-swedish.md](../../../docs/en/knowledge/02-clinical-stt-swedish.md).

```bash
./synth.sh                                   # audio/ from cases.jsonl (macOS `say`, voice Alva)
npm run stt:bench -- --arm wall-e            # score the default pipeline
npm run stt:bench -- --import arms/claude-pro.jsonl --arm claude-pro   # after PROTOCOL.md
npm run stt:loop                             # optimise against the target in loop.yaml
```

| File | Role |
|---|---|
| `glossary.yaml` | curated vocabulary → Whisper prompt + correction prompt |
| `glossary.learned.yaml` | generated by the loop from benchmark misses |
| `cases.jsonl` | 45 utterances with reference, terms, pii, tags |
| `loop.yaml` | objective, guardrails, target, budget, search space |
| `arms/` | hand-captured transcripts (Claude Pro); template included |
| `audio/`, `.cache/`, `runs/` | generated, git-ignored |
